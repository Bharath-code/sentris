Frequently Answered Questions

Does Sentris ever send my proprietary source code or raw secrets to the cloud?
No, never. All scanning, AST parsing, and remediation occur 100% locally on your machine. Upstream telemetry to Sentris Pro Cloud transmits strictly salted HMAC-SHA256 hashes and file line numbers. We cannot see your code or raw keys even if subpoenaed.
How does Dual-Key Safe Rotation prevent production downtime?
Blindly revoking a key takes down live systems. Sentris provisions the replacement key first via provider API, injects it into .env, verifies it via a non-destructive probe (e.g. Stripe Balance or AWS STS), and queues the old key with a 24-hour deprecation timer.
Why $8/seat? What if I only want the local CLI?
The CLI is 100% free forever under the MIT license (brew install sentris). The $8/seat Pro tier is for teams that want autonomous remediation, team dashboard synchronization, Slack Block Kit alerts, and SOC 2 cryptographic audit compliance.
