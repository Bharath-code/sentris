Architectural answers for Security & Staff Engineers

How does Sentris prevent production outages when rotating a leaked key?

Instant revocation causes immediate HTTP 500 outages. Sentris uses a Dual-Key Staged Lifecycle (Provisioned → Propagated → Revoked): it provisions a replacement credential in your secret store first, patches your code, and only revokes the leaked key after deployment health checks pass.

How does Zero-Knowledge Multi-Repo Blast Radius work on Cloudflare D1?

Your workstation hashes every detected credential with an organization salt using SHA-256 (zk_<hex>). Our Cloudflare Worker + D1 edge database correlates identical zk_ hashes across all repositories in under 3ms without ever seeing your raw secrets or source code.

What happens if a secret was already pushed to remote Git history (Zone 3)?

Sentris classifies findings into 3 Git Zones. For Zone 3 (pushed commits), Sentris never corrupts shared commit history with a blind rebase—instead it creates a quarantine branch (sentris/quarantine/<rule>) and outputs a copy-paste git filter-repo purge playbook.

Sentris uses Dodo Payments as our global Merchant of Record. Teams can subscribe in USD ($8/seat/mo) or INR (via UPI or cards) with automated GST, VAT, and US sales tax compliance and instant sp_live_ CLI license key provisioning.
